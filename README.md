# Практикум «ТехноМаркет» — анализ данных

## Общее описание
Реализовано все 10 блоков практического задания по аналитике данных на наборе синтетических данных компании «ТехноМаркет».

## Структура проекта

```
.
├── starter_template.py  — основной скрипт Python 
├── otchet.xlsx          — отчет в Excel 
├── vyruchka_po_kategoriyam.png  — выручка по категориям
├── vyruchka_po_mesyatsam.png    — выручка по месяцам
├── kanaly_pie.png               — пироговая диаграмма
├── top10_tovar_vyruchka.png     — топ-10 товаров по выручке
└── data/                        — исходные данные
    ├── customers.csv
    ├── orders.csv
    ├── returns.csv
    └── products.xlsx
```
### Блок 1. Загрузка и первичный осмотр
- Загрузка 4-х файлов с данными (orders, customers, returns, products)
- Вывод shapes, head(), dtypes, info(), describe() для каждой таблицы

### Блок 2. Очистка данных
- Приведение дат к формату datetime (разные форматы, dayfirst=True)
- Удаление дубликатов
- Фильтрация строк с Количество <= 0
- Заполнение пропусков: Скидка_процент → 0, Пол → "Не указан"
- Нормализация Город (strip + title)
- Очистка Бренд, расчет медианы себестоимости по категориям

### Блок 3. Признаки, фильтрация, сортировка
- Вычисление выручки: `Количество * Цена * (1 - Скидка_процент/100)`
- Расчет прибыли с использованием себестоимости из products
- Выделение полей Год, Месяц
- Топ-10 онлайн-заказов со скидкой по выручке

### Блок 4. Группировки и агрегация
- Выручка по категориям и каналам сбыта
- Средний чек (выручка за уникальный заказ)
- Агрегация метрик по категориям (revenue, profit, num_orders, avg_check)

### Блок 5. Объединение таблиц (merge)
- Широкий таблиц: orders + customers + products
- Топ-5 городов по выручке
- Выручка по сегментам клиентов

### Блок 6. Сводные таблицы и возвраты
- Pivot-таблица: Категория x Канал
- Возвраты по категориям и причинам
- Доля возвратов: **7.66%**
- Топ-5 возвращаемых товаров (Baseus Go 7 — 8 шт., Xiaomi X 14, Apple Air 6/4 — по 7 шт. каждый)

### Блок 7. Временные ряды
- Выручка по месяцам (resample "ME")
- Лучший месяц: October 2024 (25.2M руб.)
- Худший месяц: February 2023 (1.5M руб.)
- Скользящее среднее 3 месяца

### Блок 8. Визуализация (matplotlib) — сохраняйте в PNG
- 4 графика сохранены в текущую директорию:
  - vyruchka_po_kategoriyam.png
  - vyruchka_po_mesyatsam.png
  - kanaly_pie.png
  - top10_tovar_vyruchka.png

### Блок 9. Выгрузка отчёта в Excel
- `otchet.xlsx` со следующими листами:
  - Сводные_метрики — agg-метрики с форматированием (жирный шрифт, автowidth)
  - Выручка_по_категориям
  - Возвраты_по_категориям
  - Топ-5_городов
  - Выручка_по_сегментам
  - Широкая_таблица (первые 100 строк)
- Оформление через openpyxl: шапка, автоподбор ширины колонок

### Блок 10 (повышенная сложность): ABC-анализ, RFM, когорты
- **ABC-анализ**: 64% выручки приходят от A-класса (топ-20% товаров)
- **RFM-анализ**: Recency, Frequency, Monetary для каждого клиента
- **Когортный анализ**: распределение клиентов по месяцам регистрации

## Ключевые метрики
